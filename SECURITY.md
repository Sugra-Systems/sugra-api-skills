# Security

This repository ships Agent Skills (Markdown instructions). It does not ship hooks, MCP servers, or install-time scripts.

Report a vulnerability in these files to support@sugra.systems and abuse@sugra.systems. Do not open a public issue with exploit detail.

Do not put API keys in a skill file, commit, or chat. Issue keys at https://app.sugra.ai/settings/billing.

Operator secrets for self-hosted MCP (`INTERNAL_API_TOKEN`, JWKS URLs) belong in the `sugra-api-mcp` operator docs, not here.
