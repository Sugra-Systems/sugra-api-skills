# sugra-api

Official Sugra API skills. HTTPS and MCP. Plugin `sugra-api` in marketplace `sugra-api-skills`.

Layout follows Agent Skills (`SKILL.md`) plus a portable Agent Plugins manifest (`plugin.json`). Claude reads `.claude-plugin/plugin.json`. Codex / ChatGPT read `plugin.json` (`extensions.com.openai`) with `.codex-plugin/plugin.json` as fallback.

Documentation: https://docs.sugra.ai
