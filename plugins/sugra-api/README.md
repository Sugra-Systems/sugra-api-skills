# sugra-api

Official Sugra API skills. HTTPS and MCP. Plugin `sugra-api` in marketplace `sugra-api-skills`.

Published: [ChatGPT / Codex Plugins Directory](https://chatgpt.com/plugins/plugins_6aa4f7db79848191a81e4048990545ef).

Canonical package is Agent Plugins 1.0.0: root `plugin.json` (schema plus `extensions.com.openai`), `skills/`, `assets/`. Claude Code still reads `.claude-plugin/plugin.json` in this repo. Hosted MCP for Claude is `.mcp.json` (`type: http`, `https://app.sugra.ai/mcp`), the same origin as the published Anthropic Connectors Directory listing. OpenAI directory zip is the portable tree without `.claude-plugin` and without `.mcp.json`.

Documentation: https://docs.sugra.ai
